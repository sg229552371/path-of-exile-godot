## 2. AI 协作开发流程（流程铁律的可执行清单）

1. **先写文档**：任何非琐碎改动，先在 `docs/PLANNING.md` 追加决策段，或为大型事项新建专项设计文档：目标、方案、影响面、分步清单（每步带验证点）、回滚方式。
2. **再校验**：文档定稿 → 静态校验（无头跑通 / GUT / 引用影响核对），**或经用户批准方案**。
3. **后进代码**：通过才动手。每行改动可回溯到文档某一步（外科手术式，不夹带无关重构）。
4. **闭环回写**：完成后回文档补记"实际执行 + 验证结果"。
5. **每一步做成垂直切片**：一个阶段结束时必须**能玩/能验证**，不铺"半成品系统"。
6. **琐碎改动**（单行/拼写）可跳过全流程。

**AI 方法要点**（对每个 AI 会话的约束，Karpathy 四原则）：
- 陈述假设、不猜；有更简单方案就说；困惑就停下问。
- 用最少代码解决当下问题，不做投机抽象。
- 目标转可验证标准（"加校验"→"先写失败测试再让它过"）。

## 3. 模块分层与通讯规则（已生效）

> 模块分三层：**地基(纯逻辑可测)** / **组件(挂实体)** / **服务(Autoload 全局)**。

### 3.1 已就绪的地基与服务（D1 移植）

| 层 | 模块 | 数据载体 / 事件 |
| :-- | :-- | :-- |
| 服务 | `EventBus`（autoload） | `fire/on/off` + `EventKeys` 常量键 |
| 服务 | `TimeControl`（autoload） | 玩法暂停 + hitstop；`pause_changed`/`hitstop_finished` |
| 服务 | `MetaProgress`（autoload） | 跨局统计/解锁存档 |
| 服务 | `Sfx`（autoload） | 程序化合成短音（零素材；headless 禁用） |
| 服务 | `Options`（autoload） | 设置持久化（Master + Sfx 双总线） |
| 地基 | `StatModel` + `StatModifier` | `changed(stat, value)`；(base+Σflat)×(1+Σpercent) |
| 地基 | `HealthComponent` | `health_changed`/`died`；**唯一伤害入口** |
| 地基 | `DamageData`/`Hitbox`/`Hurtbox` | 伤害数据 + 攻击/受击判定 |

### 3.2 通讯通路（按强弱排序，优先用弱耦合）

1. **同实体内部：组合 + 信号**——组件挂子节点，组件发信号、实体订阅。例：`Hurtbox→实体根`。**组件不认识兄弟/上级。**
2. **跨系统解耦：EventBus**——两个互不知晓的系统传话。战斗→UI、掉落→统计都走它。**取代"满世界 get_node 找目标"。**
3. **数据载体传参：DamageData / StatModifier / Resource**——把"发生了什么/属性多强"打包成数据传下去，不在函数间传引用链。

### 3.3 数据健康六铁律（审计基准）

1. **引用方向单向向下**：场景持有组件；组件不反向持有场景逻辑根。
2. **唯一伤害入口**：扣血一律 `HealthComponent.take_damage(DamageData)`，禁止裸 `health -= n`（grep 校验）。
3. **UI 只订阅、从不被逻辑推**：HUD 监听信号/EventBus，逻辑层不碰控件。
4. **共享模板必须 per-instance `duplicate()`**（防共用一份血/状态）。
5. **跨系统不深引用**：唯一例外=场景管理器；其余用 EventBus / 信号 / 数据载体。
6. **纯逻辑不 import Node 依赖**：core 层可 GUT 直测。

## 5. 每阶段怎么验证（检验机制总表）

| 层 | 手段 | 时机 |
| :-- | :-- | :-- |
| 纯逻辑新件 | GUT 套件（`test/unit/`） | 每批 |
| Autoload / 服务 | 无头 `--quit-after 3` + MCP `project_run`/`game_eval`/`logs_read` | 每批 |
| 集成行为 | GUT 实例化场景驱动断言（不依赖物理帧） | 每阶段出口 |
| 手感 / 观感 | 编辑器 `project_run` 人工试玩 | 有玩法后 |
| 全量回归 | `/verify` = 无头自检 + 全部 GUT 绿（核对 Scripts 计数） | 每次提交前 |
